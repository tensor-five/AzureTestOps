Vertrag v1: Magic Sort für Beziehungsansicht

Freigegeben am 25. August 2026

Versprechen

Als Nutzer kann ich die sichtbare Beziehungsansicht bewusst per Magic Sort neu anordnen lassen. Das Ergebnis reduziert Linienkreuzungen und die gesamte Verbindungslänge, ohne Test Cases über ihre Suite-Grenzen zu verschieben.

Verbindliche Anforderungen

IDAnforderung
MS-01Die Beziehungsansicht zeigt einen per Tastatur bedienbaren Button Magic Sort mit Zauberstab-Symbol.
MS-02Beim Laden eines Sets, beim Aktualisieren von Daten und beim Ändern von Filtern wird Magic Sort niemals automatisch ausgeführt.
MS-03Nur ein Klick oder eine äquivalente Tastaturauslösung auf Magic Sort startet die Optimierung der aktuell sichtbaren Elemente.
MS-04Die Optimierung darf die Reihenfolge von Bugs verändern. Sie darf außerdem die Reihenfolge von Test Cases verändern, aber ausschließlich innerhalb derselben Suite; kein Test Case darf seine Suite wechseln.
MS-05Die Optimierung minimiert gemeinsam Linienkreuzungen und die gesamte Verbindungslänge. Bei mehreren gleichwertigen Ergebnissen liefert sie für dieselben sichtbaren Daten und dieselbe Ausgangsanordnung dasselbe Ergebnis.
MS-06Während der Optimierung zeigt die Ansicht echte, schrittweise angenommene Verbesserungen der Item-Positionen. Bei aktivierter Betriebssystem-Präferenz für reduzierte Bewegung wird direkt das Endergebnis angezeigt.
MS-07Nach Abschluss wird die neue Reihenfolge als Layout des aktiven Sets gespeichert und beim nächsten Laden dieses Sets wiederhergestellt.
MS-08Magic Sort stellt keine Rückgängig-Funktion bereit.
MS-09Der laufende Status ist für Screenreader verfügbar und wird nicht ausschließlich durch Farbe kommuniziert.

Nicht Teil dieses Vertrags

  • Änderungen an Azure DevOps oder an den Beziehungen selbst.
  • Eine automatische Neuanordnung ohne bewusste Nutzeraktion.
  • Das Verschieben von Test Cases zwischen Suiten.
  • Eine Rückgängig-Funktion.
