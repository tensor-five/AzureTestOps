Vertrag v1: Magic Sort mit freien Bug-Höhenslots

Freigegeben am 25. August 2026

Versprechen

Als Nutzer kann ich neben Magic Sort pro Set die Option Add Spacer aktivieren. Dann darf Magic Sort sichtbare Bugs vertikal in freien Höhenslots platzieren, damit sie näher bei ihren sichtbaren verbundenen Test Cases liegen.

Verbindliche Anforderungen

IDAnforderung
MSS-01In der globalen Header-Leiste steht unmittelbar neben dem Magic-Sort-Button eine über Tastatur und Screenreader bedienbare Checkbox mit der sichtbaren Beschriftung Add Spacer.
MSS-02Die Option ist pro Set führend über die vorhandene lokale Nutzerpräferenz-Persistenz gespeichert und nach einem Neuladen sowie beim Wechsel zurück zu diesem Set wiederhergestellt. Für Sets ohne gespeicherten Wert ist sie deaktiviert.
MSS-03Ist Add Spacer deaktiviert, bleibt das bestehende Magic-Sort-Verhalten unverändert: Bugs bilden eine lückenlose Liste und Magic Sort verändert nur Reihenfolgen.
MSS-04Ist Add Spacer aktiviert, darf jeder sichtbare Bug eine freie ganzzahlige Höheneinheit in der Bug-Spalte belegen. Freie Höhenslots werden als Leerraum dargestellt und dürfen zwischen oder vor/nach sichtbaren Bugs liegen.
MSS-05Mit aktivem Add Spacer minimiert Magic Sort für die sichtbaren, ungefilterten Beziehungen die Summe der absoluten Positionsdifferenzen und zusätzlich Linienkreuzungen. Eine angenommene Bewegung darf keinen dieser Werte verschlechtern und muss mindestens einen strikt verbessern.
MSS-06Die sichtbaren Test-Case-Positionen inklusive Suite-Kopfzeilen, Ein-/Ausklappzustand und Filtern bleiben die Bewertungsgrundlage. Test Cases dürfen weiterhin nur innerhalb ihrer Suite umsortiert werden; Beziehungen, Filter und Ein-/Ausklappzustand ändern sich nicht.
MSS-07Die freie Platzierung verhindert Überlagerungen von Bug-Karten, behält die bewusste Auslösung über Magic Sort bei und wird zusammen mit bestehenden Sortierbewegungen animiert.

Nicht Teil dieses Vertrags

  • Automatisches Sortieren beim Laden oder beim Ändern der Checkbox.
  • Manuelles Hinzufügen einzelner Spacer ohne Magic Sort.
  • Änderungen an Azure DevOps, Beziehungen oder Suite-Zugehörigkeiten.
  • Eine Rückgängig-Funktion.
