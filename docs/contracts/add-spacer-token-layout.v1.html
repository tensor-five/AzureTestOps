Vertrag v1: Add-Spacer-Token-Layout

Freigegeben am 27. August 2026

Versprechen

Mit Add Spacer ist die rechte Spalte ein gemeinsamer Stack aus Bugs und festen Spacer-Blöcken. Ein Bug kann direkt einen freien Spacer-Slot belegen — auch zwischen zwei Spacern — und wird nicht auf den Tausch mit einem anderen Bug beschränkt.

Verbindliche Anforderungen

IDAnforderung
ASTL-01Bei aktivem Add Spacer besteht die sichtbare Bug-Anordnung aus Bug-Referenzen und festen Spacer-Slots. Spacer enthalten keine Kopie von Bug-Daten.
ASTL-02Ein Bug kann auf einen freien Spacer-Slot gezogen werden und belegt anschließend genau dessen Höhe. An der ursprünglichen Bug-Höhe entsteht ein Spacer-Slot.
ASTL-03Ein Bug kann damit zwischen zwei Spacer-Slots liegen. Anzahl, Reihenfolge und Höhe aller vorhandenen Spacer-Slots bleiben bei einem manuellen Bug-Move unverändert.
ASTL-04Jeder freie Spacer-Slot zeigt beim Ziehen eines Bugs eine sichtbare Drop-Vorschau; Spacer selbst sind nicht ziehbar.
ASTL-05Die manuelle Anordnung und der Add-Spacer-Status werden pro Set über die bestehende Nutzerpräferenz gespeichert und beim erneuten Öffnen wiederhergestellt. Bereits gespeicherte Spacer-Positionen werden verlustfrei in den Stack überführt.
ASTL-06Bei aktiven Filtern werden nur sichtbare Bugs und Slots verändert. Herausgefilterte Bugs und ihre Positionen bleiben unverändert.
ASTL-07Bei deaktiviertem Add Spacer bleiben die bisherige manuelle Sortierung, Magic Sort, Filter, Linien und die übrige Bedienung unverändert. Magic Sort darf bei aktivem Add Spacer die daraus entstehenden Bug-Höhen weiterhin optimieren.

Nicht Teil dieses Vertrags

  • Neue Dialoge oder Einstellungen.
  • Manuelles Hinzufügen, Löschen oder Vergrößern von Spacer-Slots.
  • Kopien, Caches oder Änderungen an den fachlichen Bug-Daten.
