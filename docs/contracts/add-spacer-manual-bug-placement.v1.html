Vertrag v1: Manuelle Bug-Positionierung mit Add Spacer

Freigegeben am 26. August 2026

Versprechen

Ist Add Spacer aktiv, lassen sich Bugs weiterhin manuell vertikal sortieren. Spacer verhalten sich dabei wie feste, nicht verschiebbare Blöcke: Bugs werden oberhalb oder unterhalb dieser Blöcke abgelegt, ohne Spacer zu entfernen, zusammenzuführen oder zu verschieben.

Verbindliche Anforderungen

IDAnforderung
ASMB-01Bei aktivem Add Spacer bleiben die vorhandenen Drag-Handles und die Tastaturbedienung für die manuelle Sortierung von Bugs verfügbar.
ASMB-02Spacer sind sichtbare, nicht verschiebbare Höhenblöcke. Sie erhalten weder einen Drag-Handle noch können sie als Bug behandelt werden.
ASMB-03Ein Bug kann per Drag & Drop oberhalb oder unterhalb eines Bugs sowie oberhalb oder unterhalb eines Spacers abgelegt werden. Die Drop-Vorschau macht die Zielposition sichtbar.
ASMB-04Ein manueller Bug-Move ordnet Bugs um die bestehenden Spacer-Blöcke herum an. Anzahl, Reihenfolge und Höhe der Spacer-Blöcke bleiben dabei unverändert.
ASMB-05Die resultierende Bug- und Spacer-Anordnung wird pro aktivem Set über die bestehende Layout-Persistenz gespeichert und nach Neuaufruf wiederhergestellt.
ASMB-06Die manuelle Sortierung respektiert den aktiven Filter: Sie verändert ausschließlich aktuell sichtbare Bugs. Ausgeblendete Bugs und ihre gespeicherten Positionen bleiben unverändert.
ASMB-07Bei deaktiviertem Add Spacer bleiben die bisherige manuelle Sortierung, Magic Sort, Add Spacer selbst, Filter, Linien und übrige Bedienung unverändert.

Nicht Teil dieses Vertrags

  • Manuelles Anlegen, Löschen oder Vergrößern von Spacern.
  • Änderungen am Optimierungsalgorithmus von Magic Sort.
  • Veränderungen an nicht sichtbaren oder herausgefilterten Bugs.
